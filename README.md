# 拾光相簿
繁體中文相片集：多張上傳、拖放、標題／日期／地點／感性文字、文字靈感、放大導覽、相簿設定、JSON 備份與匯入。

GitHub Pages 提供靜態網頁。照片與文字保存在各自瀏覽器的 IndexedDB，並非雲端共享相簿。清除網站資料會移除內容，請定期匯出備份。上傳照片縮至最長邊 2000px 並轉為 JPEG；如需保存原始畫質，請另行保留原檔。題詞功能透過 Gemini API 將當前照片與使用者補充資料傳送給 Google，產生標題與感性說明。API 金鑰只保留在頁面的密碼欄位，不寫入 IndexedDB、備份或原始碼，重新開啟需再輸入。請僅在自己的裝置使用自己的金鑰。

相簿本身不需要金鑰；看圖寫題詞需要使用者的 Gemini API 金鑰與可用額度。可使用 `python3 -m http.server 8765` 本機預覽。

照片時間預設為上傳當下的本機日期與時間（可手動修改），不是圖片 EXIF 拍攝時間。舊照片未填日期時，以原始收藏時間顯示。
