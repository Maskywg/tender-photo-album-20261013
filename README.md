# 拾光相簿
繁體中文相片集：多張上傳、拖放、標題／日期／地點／感性文字、文字靈感、放大導覽、相簿設定、JSON 備份與匯入。

GitHub Pages 提供靜態網頁。照片與文字保存在各自瀏覽器的 IndexedDB，並非雲端共享相簿。清除網站資料會移除內容，請定期匯出備份。上傳照片縮至最長邊 2000px 並轉為 JPEG；如需保存原始畫質，請另行保留原檔。文字靈感是內建句子，沒有 AI 照片辨識。

不需要 API 金鑰。可使用 `python3 -m http.server 8765` 本機預覽。

照片時間預設為上傳當下的本機日期與時間（可手動修改），不是圖片 EXIF 拍攝時間。舊照片未填日期時，以原始收藏時間顯示。
